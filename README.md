# Guía de Git y GitHub con Visual Studio Code

Guía práctica paso a paso para aprender a utilizar **Git** y **GitHub** desde **Visual Studio Code**.

Este repositorio está pensado como material de consulta para estudiantes que necesitan aprender o recordar cómo trabajar con repositorios, subir proyectos, actualizar cambios y solucionar errores frecuentes.

---

## ¿Qué aprenderás?

A lo largo de esta guía aprenderás a:

- Comprender qué es Git y qué es GitHub.
- Configurar Git en tu equipo.
- Trabajar con Git desde Visual Studio Code.
- Crear repositorios.
- Subir proyectos existentes a GitHub.
- Clonar repositorios.
- Actualizar proyectos.
- Realizar commits.
- Utilizar `push` y `pull`.
- Trabajar con ramas.
- Resolver errores frecuentes.
- Utilizar GitHub en trabajos colaborativos.

## Metodología

Cada tema estará explicado paso a paso e incluirá:

- Explicación del procedimiento.

- Descripción de lo que hace cada comando.
- Resultado esperado.
- Forma de verificar que el proceso funcionó correctamente.
- Errores frecuentes y posibles soluciones.
